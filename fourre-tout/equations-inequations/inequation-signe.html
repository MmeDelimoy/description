Inéquation du 1er degré : savoir quand le signe change

Objectif
Résoudre une inéquation du 1er degré et savoir quand il faut changer le sens du signe.
Feuille d’explication

1. Ce qui ne change jamais le sens

Ajouter ou soustraire le même nombre aux deux membres.

x + 3 < 7  ⇒  x < 4

Multiplier ou diviser les deux membres par un nombre positif.

3x < 12  ⇒  x < 4

2. Ce qui inverse le sens

Multiplier ou diviser par un nombre négatif.

On sait que 2 < 5. On multiplie par −1 : les nombres passent de l’autre côté de zéro, et l’ordre s’inverse.

2 < 5  mais  −2 > −5

3. Pourquoi ? Le lien avec les fonctions

Croissante : l’ordre est conservé. Pour tous x₁ < x₂, on a f(x₁) < f(x₂).
Décroissante : l’ordre est inversé. Pour tous x₁ < x₂, on a f(x₁) > f(x₂).

f(x) = 0,5x + 1,5 : croissante
x₁ < x₂ donne f(x₁) < f(x₂)
g(x) = −0,5x + 2 : décroissante
x₁ < x₂ donne g(x₁) > g(x₂)

Multiplier par un nombre k, c’est appliquer la fonction x ↦ kx. Si k > 0 elle est croissante (ordre conservé). Si k < 0 elle est décroissante : l’ordre est inversé, donc le sens du signe aussi.

4. Méthode

−2x + 1 > 7

−2x > 6  (on soustrait 1 des deux côtés)
x < −3  (on divise par −2 : le sens change)
S = ]−∞ ; −3[

Contrôle : x = −4 donne −2·(−4) + 1 = 9 > 7 ✓

Rappel : un crochet est fermé si le nombre est inclus (≤, ≥), ouvert sinon (<, >). L’infini est toujours ouvert.
